# ケアハウス記録管理システム - 現場改善版

高齢者福祉施設・ケアハウス等の現場業務に特化した、Google スプレッドシート連携型の支援記録管理システムです。

スマートフォンやタブレットからの入力・閲覧に最適化されており、音声入力や監査対応の検索・CSV出力機能を備えています。

---

## 1. システム概要と特長

* **Google スプレッドシートをDB化**: クラウドサーバー契約不要で、スプレッドシートをデータベースとして活用。
* **音声入力＆バイタル自動整形**: Web Speech API を活用し、「体温36度5分」「血圧120の80」といった音声を自動で整形して記録。
* **複数人の一括入力 / 直前コピー**: レクリエーションや食事記録など、複数名同時の記録作成や連続入力を効率化。
* **監査対応（運営指導対応）**: 年度単位（今年度・昨年度）の期間指定ショートカット、条件付きCSV一括エクスポート（Excel文字化け防止BOM付き）。
* **スマート読み込みによる高速化**: 通常時は直近データ（下部500行）のみを抽出し、データ蓄積時も画面表示速度を維持。
* **二重登録防止・排他制御**: `LockService` による同時書き込み制御を実装。
* **スプレッドシート直接編集の自動補完**: シート上で直接行を追加した際も、`onEdit` トリガーによりUUIDの発行やマスタIDの逆引き自動補完を実行。

---

## 2. システム構成・技術スタック

* **フロントエンド**: HTML5 / CSS3 / JavaScript (Vanilla)
* UIフレームワーク: Bootstrap 5.3.0
* セレクトボックス強化: Choices.js
* 音声認識: Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`)


* **バックエンド**: Google Apps Script (GAS)
* Web API (JSON over POST)
* 認証: SHA-256 による施設接続キー照合


* **データベース**: Google スプレッドシート

## 4. 導入・セットアップ手順

### Step 1. スプレッドシートとGASの準備

1. 新規Googleスプレッドシートを作成し、上記のシート構成（マスタ3種、記録データ）を作成します。
2. メニューバーの **[拡張機能] > [Apps Script]** を開きます。
3. デフォルトのコードを削除し、本システムの `コード.gs` を貼り付けて保存します。

### Step 2. GASのWebアプリデプロイ

1. Apps Script 画面右上の **[デプロイ] > [新しいデプロイ]** をクリックします。
2. 種類の選択で **[ウェブアプリ]** を選択します。
3. 以下の通り設定します：
* **次のユーザーとして実行**: `自分`
* **アクセスできるユーザー**: `全員`


4. **[デプロイ]** をクリックし、発行された **ウェブアプリのURL** (`[https://script.google.com/macros/s/](https://script.google.com/macros/s/)...`) を控えます。

### Step 3. フロントエンドの準備

1. `index.html` を任意のWebサーバー、または GitHub Pages / Cloudflare Pages / 社内共有サーバー等に配置します。
2. ブラウザで `index.html` にアクセスします。

### Step 4. 初期連携設定

1. 初回起動時は「🔗 システム初期設定」画面が表示されます。
2. 以下の項目を入力して **[システムに連携して開始する]** を押します：
* **WebアプリURL**: Step 2 で取得したGASのURL
* **施設ID**: 任意の英数字（例: `carehouse_001`）
* **施設接続キー**: 任意のパスワード（8文字以上）


3. 連携が成功するとスプレッドシートに非表示の「システム設定」シートが作成され、利用可能になります。
4. 2台目以降の端末（現場スタッフのスマートフォン等）でも、同じ「URL」「施設ID」「施設接続キー」を入力することで共通利用が可能です。

## 5. 主な機能と利用方法

### 支援記録 入力

* **個別・一括入力切り替え**: 「複数人入力」スイッチをONにすることで、同一の記録内容を一括で複数名の利用者に紐付けて登録可能。
* **音声入力**: 「🎤 音声入力スタート」をタップして発話。バイタル数値（体温、SpO₂、血圧、脈拍）や句読点、改行の音声コマンドを自動テキスト変換。
* **直前の入力をコピー**: 直前に保存した内容をフォームに再呼び出しし、微修正して連続登録可能。

### 記録の確認・検索

* **発生日時基準の降順表示**: 常に最新の記録が先頭に並びます。
* **監査向け期間指定**:
* **[今年度] / [昨年度]**: 日本の会計・介護保険年度（4/1〜翌3/31）に基づき、ワンタップで日付を自動セット。
* **任意期間**: カレンダーから複数年度をまたぐ期間指定が可能。


* **CSV出力 (Excel用)**:
* 検索・絞り込み結果を1クリックでCSV出力。
* BOM付きUTF-8形式で書き出されるため、Excelで直接開いても文字化けせず、セル内改行も保持。



### マスタ管理（名簿設定）

* **利用者・スタッフの追加**: 画面から直接新規追加が可能（IDは連番で自動付与）。
* **状態切り替え**: 名簿一覧の各行をタップするだけで、ステータス（利用中 / 入院中 / 退去、在籍 / 退職）を変更可能。
* **管理者メニュー（隠しコマンド）**:
* 「⚙️ マスタ管理」のタイトル部分を素早く5回タップすると、システム連携情報の確認および端末連携リセットボタンが表示されます。



### スプレッドシート直接編集時の補助機能

* **`onEdit`（自動補完）**: PC等で「記録データ」シートに直接入力した際、記録ID（UUID）の自動発行や、氏名からマスタIDの自動紐付け（スペース正規化対応）を実行。
* **`fixMissingIdsInPastRecords`（手動一括補完）**: 過去データ復元等でIDが空欄になった行に対して、Apps Scriptエディタから手動実行することでマスタとの照合・補完を一括処理。

## 6. 保守・運用上の注意点

1. **コード修正時のデプロイ手順**
`コード.gs` を修正した際は、必ず **[デプロイ] > [デプロイを管理]** を開き、鉛筆アイコンから **バージョンを「新バージョン」** に切り替えて更新してください（URLは変更されません）。
2. **データ肥大化への対応**
現在の検索処理は「通常時: 下部500行のみ」「検索時: 全行対象」のスマート読み込みを採用しています。年間数千行規模であれば、シートを物理分割せず数年間そのまま高速に運用可能です。
